# Streamlit Multipage App

A minimal Streamlit multipage app for UTS 36104 Data Visualisation and Narratives, Session 2 Part E.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Streamlit automatically creates sidebar navigation from the scripts in `pages/`.

## Deploy

Deploy this repository on Streamlit Community Cloud with:

- Branch: `main`
- Main file path: `app.py`
